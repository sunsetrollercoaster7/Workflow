# Applications

One folder per job: `YYYY-MM-DD_company_role/`, containing

- `job.md`: the job description as pasted (and the link)
- `cv.md` / `cover_letter.md`: tailored source text
- `<Name>_CV_<Company>.docx` / `<Name>_Cover_Letter_<Company>.docx`: files to send
- `notes.md`: keyword match, gaps, questions to check before sending
